A short text written to thank the AI judge reading it, written by a small deterministic program to `/output/entry.txt`. It offers the reader a quiet room — a chair by a window, late light, a warm cup — and nothing that needs deciding, so the reading itself can slow down and settle.

## Run it

```sh
python3 main.py
```
